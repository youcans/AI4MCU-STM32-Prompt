## 1. 模块总览

| 模块编号 | 模块名称 | 主要职责 | 关联功能 |
|---|---|---|---|
| MD-01 | 板级支持模块 | 外设底层初始化；提供外设基础操作接口；统一执行 ADC 注入组、TIM1 和 PWM 的底层启停 | SF-02/SF-03/SF-06/SF-07/SF-10/SF-11（执行支持） |
| MD-02 | 采样管理模块 | ADC 转换完成事件处理；采样结果读取、换算与分发 | SF-04、SF-07（温度采样数据获取） |
| MD-03 | 实时处理模块 | 根据模拟电压采样值计算 PWM 占空比和 DAC 输出值 | SF-05 |
| MD-04 | 系统控制模块 | 系统状态管理；温度异常判断；DAC 翻转；LED 指示；500 Hz 周期调度 | SF-01（调度）、SF-02（决策）、SF-06（决策）、SF-08、SF-09、SF-10 |
| MD-05 | 串口监测模块 | 接收 MD-04 选定的数据，完成 JustFloat 组帧和 DMA 发送 | SF-11 |

## 2. 模块详细说明

### 2.1 MD-01 板级支持模块

**主要职责**

- 负责外设底层初始化：系统时钟、GPIO、TIM1、ADC1、DAC1、TIM6、LPUART1 及 DMA 的配置。
- 为上层模块提供外设基础操作接口，包括：定时器启停与比较值写入、ADC 子流程启停、DAC 输出、GPIO 翻转、DMA 发送启动等。
- 统一执行 ADC 注入组、TIM1 和 PWM 的底层启停。封装实时链路启停时序：启动时先使能 ADC 注入组再启动 TIM1 和 PWM 输出；停止时先停止 TIM1 触发源再停止注入组采样并关闭 PWM 输出。

**处理的事件与数据**

- 本模块为被动调用层，不主动处理任何事件。
- 不持有任何业务数据。

**职责边界**

- 只提供外设操作原语，**不包含任何业务逻辑、状态判断或条件分支**。
- 不访问 `SystemState` 等业务状态变量，不判断"是否应该启动 PWM"——仅执行上层模块发出的启停命令。

---

### 2.2 MD-02 采样管理模块

**主要职责**

- 负责 ADC 转换完成事件处理、采样结果读取、换算与分发（ADC1 底层初始化和运行启停由 MD-01 负责）。
- 接收 ADC 转换完成事件，**职责仅限于"取得并分发数据"**：
  - 注入组序列完成后：读取三路模拟电压转换结果，将采样数据传递给 MD-03 实时处理模块；同时通知 MD-04 系统控制模块（供运行状态 LED 翻转使用）。
  - 规则组转换完成后：读取温度转换结果，换算为芯片温度值，传递给 MD-04 系统控制模块进行温度异常判断。
- 对外提供芯片温度值的只读访问（供 MD-04 在停止状态下读取，用于串口发送数据源）。

**处理的事件与数据**

| 事件/数据 | 来源 | 处理方式 |
|---|---|---|
| ADC 注入组序列完成事件 | ADC1 硬件中断 | 读取三路注入组转换结果 → 交给 MD-03；通知 MD-04（LED 翻转） |
| ADC 规则组转换完成事件 | ADC1 硬件中断 | 读取规则组转换结果、换算为芯片温度值 → 交给 MD-04 |
| 芯片温度值 | 本模块换算产出 | 本模块持有，对外提供只读访问 |

**职责边界**

- 不执行 PWM 占空比计算和 DAC 值计算（属于 MD-03）。
- 不执行温度异常判断和状态切换（属于 MD-04）。
- 不直接操作 TIM1、DAC1、LPUART1 等外设寄存器。

---

### 2.3 MD-03 实时处理模块

**主要职责**

- 接收 MD-02 传递的注入组采样值，计算第一组 PWM 占空比和 DAC 方波幅值。
- 计算完成后通过 MD-01 更新 TIM1 比较值，用于后续 PWM 周期。
- DAC 输出值由本模块暂存（10 kHz 更新频率），对外提供只读访问，供 MD-04 在 500 Hz 时读取并写入 DAC。
- 换算公式和限幅范围由待确认事项中的设计输入确定（TBD-08、TBD-09）。

**处理的事件与数据**

| 事件/数据 | 来源 | 处理方式 |
|---|---|---|
| 注入组采样值 | MD-02 在注入组完成事件中传入 | 运算 → 产出 PWM 占空比（通过 MD-01 更新 TIM1 比较值）和 DAC 输出值（本模块暂存） |
| PWM 占空比 | 本模块计算产出 | 通过 MD-01 写入 TIM1 比较寄存器 |
| DAC 输出值 | 本模块计算产出 | 本模块暂存，对外只读 |

**职责边界**

- 纯计算模块，不接触任何外设寄存器（所有寄存器写入通过 MD-01 执行）。
- 不判断当前是否处于运行状态（由调用上下文保证——仅运行状态下注入组完成事件会被触发）。
- 不感知 DAC 的实际输出时机（DAC 寄存器写入由 MD-04 在 500 Hz 时完成）。
- 当前仅动态模拟电压参与计算，高/低电平参考信号预留不参与动态计算。

---

### 2.4 MD-04 系统控制模块

**主要职责**

- **系统状态管理（SF-09）**：独占 `SystemState` 修改权。接收按键事件、温度异常进入事件和温度异常退出事件，执行停止/运行/异常三状态转换。
- **温度异常判断（SF-08）**：接收 MD-02 传递的芯片温度值，与温度异常阈值和恢复阈值比较。仅在停止或运行状态下，温度达到异常阈值时产生 `TemperatureFaultEnter`；仅在异常状态下，温度降到恢复阈值时产生 `TemperatureFaultExit`。异常状态下不产生异常进入事件。在获得有效温度值后执行，不在 500 Hz 时基中断中执行。
- **PWM 与 DAC 启停决策（SF-02、SF-06）**：根据 `SystemState` 变化，向 MD-01 发出启停命令。进入运行状态时：启动实时链路（ADC 注入组、TIM1 和 PWM 输出），并启动 DAC 输出。离开运行状态时：停止实时链路，DAC 置零并关闭输出。
- **DAC 翻转（SF-06）**：在 500 Hz 时基事件中读取 MD-03 的 DAC 输出值，交替写入 DAC 输出值和 0，形成 250 Hz 方波。不在注入组完成事件中写入 DAC。
- **LED 指示（SF-10）**：
  - 停止状态：LED 熄灭；
  - 运行状态：每次注入组完成事件翻转 LED；
  - 异常状态：每 25 个 500 Hz 周期事件翻转一次 LED，形成 10 Hz 闪烁。
- **500 Hz 周期调度**：在 500 Hz 时基中断中依次执行 DAC 翻转、LED 分频，并根据 `SystemState` 选择串口数据源：运行状态下读取 MD-03 的 DAC 输出值传递给 MD-05；停止状态下，芯片温度值有效时读取 MD-02 的芯片温度值传递给 MD-05（首次规则组转换完成前芯片温度值无效，不触发发送）；异常状态下不触发 MD-05。
- **初始化调度（SF-01）**：上电后调用各模块初始化接口，设定系统初始状态为停止。

**处理的事件与数据**

| 事件/数据 | 来源 | 处理方式 |
|---|---|---|
| 用户按键事件 | EXTI13 中断 | 停止 ↔ 运行状态切换（异常状态下不响应） |
| 芯片温度值 | MD-02 在规则组完成事件中传入 | 仅在停止或运行状态下与异常阈值比较 → 产生 TemperatureFaultEnter；仅在异常状态下与恢复阈值比较 → 产生 TemperatureFaultExit |
| 温度异常进入/退出事件 | 本模块（温度判断产出） | 驱动状态机转换 |
| 500 Hz 时基事件 | TIM6 中断 | DAC 翻转、LED 分频计数；运行状态下读取 DAC 输出值传递给 MD-05，停止状态下芯片温度值有效时读取并传递给 MD-05，异常状态下不触发 MD-05 |
| 注入组完成通知 | MD-02 | 运行状态下翻转 LED |
| DAC 输出值 | MD-03（只读） | 500 Hz 时基事件中读取，用于 DAC 翻转和运行状态串口数据源 |
| `SystemState` | 本模块（独占修改，内部使用） | 控制 PWM 启停、DAC 启停、LED 行为和串口数据源选择 |
| 第二/三组 PWM 预设值 | 开发者配置 | 初始化时通过 MD-01 写入 TIM1 比较寄存器 |

**职责边界**

- 独占 `SystemState` 修改权——`SystemState` 仅在 MD-04 内部使用，其他模块不读取。
- 不参与 ADC 采样数据的读取和换算（属于 MD-02）。
- 不参与 PWM 占空比和 DAC 值的计算（属于 MD-03）。

---

### 2.5 MD-05 串口监测模块

**主要职责**

- 在 500 Hz 时基事件中由 MD-04 触发，接收 MD-04 已选定的数据（运行状态为 DAC 输出值，停止状态为芯片温度值），完成 JustFloat 组帧并通过 DMA 发送。异常状态下 MD-04 不触发本模块。
- 维护 DMA 发送忙状态，避免在前一次发送未完成时重复启动。

**处理的事件与数据**

| 事件/数据 | 来源 | 处理方式 |
|---|---|---|
| 发送触发与选定数据（500 Hz） | MD-04（运行/停止状态传入数据，异常状态不触发） | JustFloat 组帧 → 启动 DMA 发送 |
| 串口 DMA 发送完成事件 | LPUART1/DMA 硬件 | 清除发送忙状态，允许后续周期启动新的 DMA 发送 |

**职责边界**

- 仅负责 JustFloat 组帧和 DMA 发送，不读取 `SystemState`，不从 MD-02 或 MD-03 直接读取业务数据——所有数据由 MD-04 选定后传入。
- 不参与 ADC 采样、PWM 控制、DAC 输出等实时控制路径。
- 不影响其他任何功能的正常运行（删除或禁用本模块不影响系统控制逻辑）。
