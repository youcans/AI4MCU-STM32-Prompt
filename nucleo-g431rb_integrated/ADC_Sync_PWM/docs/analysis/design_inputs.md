## 1. 项目名称

基于 ADC 同步采样的 PWM 占空比控制

---

## 2. 项目目标

在 NUCLEO-G431RB 开发板上，以 PWM 周期事件触发三通道模拟电压同步采样，在每次采样序列完成后执行一次实时数据处理，根据动态模拟电压的采样结果更新 PWM 占空比和 DAC 输出，同时实现芯片温度监测、系统状态切换、LED 指示和串口数据发送功能。

---

## 3. 项目功能要求

| 编号 | 功能名称 | 概要 |
|---|---|---|
| FR-01 | PWM 输出与周期事件 | 输出三组 10 kHz 带死区互补 PWM，第一组占空比动态更新，第二/三组使用预设值；产生 ADC 采样触发事件 |
| FR-02 | ADC 三通道同步采样 | PWM 周期事件触发三通道模拟电压采样，一路动态电压、两路参考电平 |
| FR-03 | 实时数据处理 | 每次采样序列完成后执行，读取采样值、计算并更新 PWM 占空比和 DAC 输出 |
| FR-04 | DAC 参考方波输出 | 输出固定频率参考方波，幅值随动态模拟电压采样结果更新 |
| FR-05 | 芯片温度监测 | 使用内部温度传感器以 500 Hz 采集芯片温度，全状态持续运行 |
| FR-06 | 温度异常处理 | 温度超限进入异常状态，温度恢复返回停止状态 |
| FR-07 | 系统状态切换 | 停止/运行/异常三状态，按键切换停止↔运行，温度触发异常进入与恢复 |
| FR-08 | LED 状态指示 | 停止熄灭、运行翻转（~常亮）、异常 10 Hz 闪烁 |
| FR-09 | 串口数据发送 | JustFloat / 115200 bps / 500 Hz，运行发送 DAC 值，停止/异常发送温度 |

### FR-01 PWM 输出与周期事件

系统输出三组带死区的互补 PWM 信号，频率均为 10 kHz。

第一组 PWM 的占空比根据动态模拟电压的采样结果实时更新。第二组和第三组 PWM 使用预设占空比，不随采样结果动态变化。

PWM 定时器同时产生 10 kHz 周期事件，在运行状态下用于触发 ADC 三通道同步采样。

在停止状态和异常状态下，三组 PWM 输出全部关闭。

### FR-02 ADC 三通道同步采样

系统通过 PWM 周期事件触发三通道模拟电压采样，三个通道在同一次触发后按预定顺序完成转换。

三个 ADC 通道的输入信号分别为：
- 第一路：电位器提供的动态模拟电压，用于驱动 PWM 占空比更新和 DAC 输出；
- 第二路：高电平参考信号，当前不参与动态计算；
- 第三路：低电平参考信号，当前不参与动态计算。

本实验可进一步扩展为输入三路动态模拟电压。

模拟电压采样仅在运行状态下启动。在停止状态和异常状态下，模拟电压采样停止。

### FR-03 实时数据处理

运行状态下，每次三通道模拟电压采样序列完成后，系统执行一次实时数据处理，依次完成以下操作：
- 读取三路原始采样值；
- 对动态模拟电压通道的采样值进行数据转换，计算 PWM 占空比和 DAC 输出值；
- 更新第一组 PWM 占空比；
- 更新 DAC 输出值。

停止状态和异常状态下，由于模拟电压采样已停止，实时数据处理不执行。

模拟电压采样、实时数据处理、PWM 更新和 DAC 更新之间保持稳定的周期关系。

### FR-04 DAC 参考方波输出

运行状态下，DAC 输出固定频率的参考方波，方波幅值根据动态模拟电压的最新采样结果在每次实时数据处理中更新。

在停止状态和异常状态下，DAC 输出关闭。

### FR-05 芯片温度监测

系统使用 MCU 内部温度传感器采集芯片温度。温度采样频率为 500 Hz。

温度监测在停止、运行和异常三种状态下均持续执行，不随系统状态切换而中断。

温度监测结果用于两项用途：一是提供给温度异常处理功能进行阈值比较，二是在停止状态和异常状态下作为串口发送的数据内容。

### FR-06 温度异常处理

系统设置温度异常阈值和温度恢复阈值，两者为独立阈值以避免临界抖动。

当芯片温度达到异常阈值时，系统自动进入异常状态。当芯片温度下降到恢复阈值时，系统自动退出异常状态并返回停止状态。温度超限可从运行状态或停止状态触发。

异常状态下的系统行为：
- 停止模拟电压实时采样；
- 关闭全部三组 PWM 输出；
- 关闭 DAC 输出；
- 继续执行芯片温度采样；
- 继续执行串口数据发送，发送内容为芯片温度。

本项目仅处理芯片温度异常，采样超时、串口通信错误、看门狗复位等其他异常不纳入本项目功能范围。

### FR-07 系统状态切换

系统设置停止、运行和异常三种状态，各状态下各项功能的行为如下：

- 停止状态：模拟电压采样停止，PWM 输出关闭，DAC 输出关闭，实时数据处理不执行；芯片温度监测继续运行，串口数据发送继续运行（发送芯片温度）；LED 熄灭。
- 运行状态：模拟电压采样启动（10 kHz），PWM 输出开启（10 kHz），DAC 输出开启，实时数据处理执行（10 kHz）；芯片温度监测继续运行（500 Hz），串口数据发送继续运行（500 Hz，发送 DAC 当前输出值）；LED 在每次采样序列完成后翻转，肉眼观察近似常亮。
- 异常状态：模拟电压采样停止，PWM 输出关闭，DAC 输出关闭，实时数据处理不执行；芯片温度监测继续运行，串口数据发送继续运行（发送芯片温度）；LED 以 10 Hz 频率闪烁。

状态切换规则如下：
- 用户按下板载用户按键，在停止状态和运行状态之间切换；
- 芯片温度达到异常阈值时，从当前状态自动进入异常状态；
- 芯片温度下降到恢复阈值时，从异常状态自动返回停止状态；
- 异常状态下，用户按键不产生状态切换；
- 系统返回停止状态后，需用户再次按下按键才能进入运行状态。

### FR-08 LED 状态指示

系统使用板载用户 LED 指示系统状态和实时处理运行情况。

三种状态下的 LED 行为：
- 停止状态：LED 熄灭；
- 运行状态：每次模拟电压采样序列完成后翻转一次 LED 输出，肉眼观察近似常亮；
- 异常状态：LED 以 10 Hz 频率闪烁。

### FR-09 串口数据发送

系统通过串口向上位机 VOFA+ 发送数据，使用 JustFloat 数据格式，波特率为 115200 bit/s，发送频率为 500 Hz。

发送内容随系统状态切换：
- 停止状态：发送芯片温度采样结果；
- 运行状态：发送 DAC 当前输出值；
- 异常状态：发送芯片温度采样结果。
