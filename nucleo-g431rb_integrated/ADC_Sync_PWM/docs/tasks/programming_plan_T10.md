## 1. 验证目标

在 T04～T09 全部完成的基础上，对系统进行完整的端到端综合验证，确认 PWM、DAC、LED、串口、温度采样、按键和状态转换在所有运行状态下协同工作正常。

---

## 2. 验证前提

| 前提 | 说明 |
|---|---|
| 固件 | T09 完成后的当前系统固件 |
| 温度阈值 | FAULT > 45°C，RECOVERY < 40°C |
| CH2/CH3 预设 | CH2=800(10%)、CH3=1600(20%) |
| 观测工具 | 示波器（PA4 DAC、PA8/PB13 PWM、PA5 LED）、VOFA+（串口数据） |
| 硬件连接 | PA1 接电位器，PB1 接 3.3V，PB0 接 GND，JP8=[2-3] |

---

## 3. 验证项目和操作步骤

### 3.1 STOP 状态验证

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 上电 | LED 熄灭；VOFA+ 收到约 500 Hz float 温度数据（约 33°C） |
| 2 | 示波器观察 PA8、PA4 | PA8 无 PWM 输出，PA4 无 DAC 输出 |
| 3 | 旋转电位器 | VOFA+ 仍显示温度数据，旋转电位器不会引起温度数据随之变化 |

### 3.2 RUN 状态验证

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 按 B1 进入 RUN | LED 常亮（10 kHz 注入组回调翻转） |
| 2 | 示波器观察 PA8 | 10 kHz PWM，中心对齐，占空比随电位器变化 |
| 3 | 示波器观察 PB13 | 与 PA8 互补输出，带死区（约 200 ns） |
| 4 | 示波器观察 PA9、PA10 | 10 kHz PWM，固定占空比（CH2=10%、CH3=20%），不受电位器影响 |
| 5 | 示波器观察 PA4 | 250 Hz 方波，幅值随电位器变化 |
| 6 | VOFA+ 观察 | 收到约 500 Hz float DAC 幅值数据，旋转电位器时数值变化 |
| 7 | 按 B1 返回 STOP | LED 熄灭，PA8/PA4 输出关闭，VOFA+ 切回温度数据 |

### 3.3 STOP ↔ RUN 反复切换

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 重复按 B1 进行多次 STOP↔RUN 切换（每次间隔大于消抖时间） | 每次切换均可靠响应，LED、PWM、DAC、串口数据正确对应状态；无一次按键产生多次状态切换 |

### 3.4 RUN 状态下动态响应

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 缓慢旋转电位器从最小到最大 | CH1 占空比从 0% 平滑变化到接近 100%，DAC 幅值从 0 平滑变化到接近 4095 |
| 2 | VOFA+ 观察数据 | 数值跟随电位器平滑变化 |

### 3.5 连续运行验证

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 按 B1 进入 RUN | LED 常亮，PWM/DAC/串口正常工作 |
| 2 | 保持 RUN 状态连续运行 60 分钟 | 期间适当调节电位器，观察 PWM、DAC、LED 和串口是否持续正常，确认 PWM 占空比和 DAC 幅值随电位器变化正确 |
| 3 | 观察全过程 | LED 持续常亮，VOFA+ 数据连续无中断，PWM/DAC 波形稳定，无程序卡死或外设异常停止 |

### 3.6 FAULT 状态验证

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 在 RUN 状态下加热 MCU | 温度 >45°C 时 LED 变为 10 Hz 闪烁；PA8/PB13、PA9、PA10 PWM 均停止，PA4 DAC 输出关闭，VOFA+ 停止发送 |
| 2 | 按 B1 | 无响应，状态保持 FAULT |
| 3 | 停止加热，等待降温 | 温度 <40°C 时 LED 熄灭，VOFA+ 恢复温度数据 |
| 4 | 按 B1 | 可进入 RUN，LED 常亮，PWM/DAC/串口恢复正常 |

---

## 4. 通过判据

| 验证项 | 判据 |
|---|---|
| STOP 状态 | LED 熄灭、PWM/DAC 关闭、VOFA+ 发温度数据 |
| RUN 状态 | LED 常亮、CH1 动态 PWM + CH2/CH3 固定 PWM + DAC 250 Hz 方波、VOFA+ 发 DAC 幅值 |
| 动态响应 | CH1 占空比和 DAC 幅值随电位器平滑变化 |
| 启停切换 | 反复按键切换可靠，无一次按键产生多次状态切换 |
| 连续运行 | RUN 状态持续 60 分钟，PWM/DAC/LED/串口正常，无卡死或异常停止 |
| FAULT 进入 | 加热超阈值 → LED 10 Hz 闪烁、PWM/DAC/串口全部停止、按键不响应 |
| FAULT 恢复 | 降温至恢复阈值 → 自动回 STOP、LED 熄灭、串口恢复、不自动回 RUN |
| 恢复后重新进入 | 按键可重新进入 RUN，全功能恢复 |

## 5. 异常记录要求

| 异常类型 | 记录内容 |
|---|---|
| 频率偏差 | 记录示波器实测 PWM 频率、DAC 方波频率、串口发送频率 |
| 死区异常 | 记录 CH1/CH1N 互补波形是否存在同时导通 |
| 数据异常 | 记录 VOFA+ 数据是否卡顿、跳变或中断 |
| 切换异常 | 记录按键切换时 LED/PWM/DAC 是否与状态不一致 |
| 温度阈值偏差 | 通过调试器记录实际触发 FAULT 和恢复 STOP 时的温度值 |

## 8. 接口及调用关系

**无调整**。验证覆盖全部已实现链路：10 kHz 注入采样（MD-02）→ 实时处理（MD-03）→ CCR1/DAC 幅值（MD-01）；500 Hz 调度（MD-04）→ DAC 翻转/串口数据源（MD-05）；按键与温度事件（MD-04 状态机）。

## 9. 编译、调试和板级验证方法

- **编译/烧录**：使用 T09 已完成固件烧录（本任务无代码变更，无需重新编译）。
- **调试/观测**：按 §3 的步骤执行——目视 LED（熄灭/常亮/10 Hz 闪烁）、示波器（PA8/PB13/PA9/PA10 PWM、PA4 250 Hz 方波、PA5 LED）、VOFA+（JustFloat、115200 bps）；
- FAULT 项的温度阈值观察：进入 FAULT 记录串口停止前最后的温度值，恢复以 LED 熄灭、串口恢复为判断依据（与 T09 校订一致）；如需精确阈值数据，可用调试器观察 `chip_temperature`（温度采样在 FAULT 期间持续运行）。

## 10. 实施顺序建议

1. 准备验证环境（§2 前提：接线、VOFA+、示波器、加热工具）；
2. 按 §3.1 → §3.2 → §3.3 → §3.4 → §3.5 → §3.6 顺序执行六项验证；
3. 按 §5 记录异常（如有）；
4. 按 §6 格式将验证结论记录至 `docs/logs/task_log.md`，全部通过后任务清单关闭。

## 11. 风险与注意事项

| 事项 | 说明 |
|---|---|
| 死区观测 | §3.2 步骤 3 的约 200 ns 死区对应 tim.c DeadTime=32（t_dts=6.25 ns ×32），示波器需足够带宽观察 |
| 加热控制 | §3.6 使用低温档热风，避免过热损坏芯片；FAULT 期间串口停发，温度观察按 §9 方法 |
| 消抖间隔 | §3.3 反复切换时每次间隔需大于 50 ms 消抖时间，否则按键被正确忽略属预期行为 |
| 任务清单备注 | T10 为最终综合验证，若发现任何问题按 §5 记录并回退到相应任务的修改计划处理 |
