[实验名称] 基于 ADC 同步采样的 PWM 占空比控制
[开发板和 MCU 型号]NUCLEO-G431RB 开发板，搭载 STM32G431RBT6 MCU
[功能目标]在 NUCLEO-G431RB 开发板上，利用 PWM 周期事件触发三通道模拟电压同步采样。每次采样序列完成后执行一次实时数据处理，根据采样结果动态更新 PWM 占空比和 DAC 输出，同时实现芯片温度监测、系统状态切换、LED 指示及串口数据发送功能。

[Experiment Name] PWM Duty Cycle Control Based on ADC Synchronous Sampling
[Board and MCU] NUCLEO-G431RB development board, equipped with STM32G431RBT6 MCU
[Objective] On the NUCLEO-G431RB development board, use PWM period events to trigger synchronous sampling of three analog voltage channels. After each sampling sequence is completed, perform real-time data processing once. Based on the sampling results, dynamically update the PWM duty cycle and DAC output. At the same time, implement chip temperature monitoring, system state switching, LED indication, and serial data transmission.
