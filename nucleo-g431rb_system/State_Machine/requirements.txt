[实验名称] 状态机实验
[功能目标] 使用有限状态机组织系统运行流程，实现由按键事件和超时事件驱动的状态转移：
  1. 设置空闲、运行、暂停和完成四种状态；
  2. 检测用户按键 B1，对按键输入进行消抖处理，每次有效按下产生一个按键事件；
  3. 空闲状态下按下 B1 进入运行状态，运行状态下按下 B1 进入暂停状态，暂停状态下按下 B1 恢复运行状态；
  4. 暂停期间不累计有效运行时间，恢复运行后继续累计剩余时间；
  5. 累计有效运行时间达到 10 秒后进入完成状态，完成状态持续 3 秒后返回空闲状态；
  6. 根据当前状态控制 LD2，使其保持熄灭、慢速闪烁、保持点亮或快速闪烁；
  7. 按键扫描、状态机处理、LED 控制和时间管理在主循环中协同运行，不使用阻塞式延时。
[开发板和 MCU 型号] NUCLEO-G431RB 开发板和 STM32G431RBT6 MCU。

[Experiment Name] State Machine Experiment
[Objectives] Use a finite state machine to organize the system operation flow and implement state transitions driven by button events and timeout events:
  1. Set up four states: Idle, Running, Paused, and Completed;
  2. Detect user button B1, debounce the button input, and generate a button event on each valid press;
  3. Pressing B1 in the Idle state enters the Running state, pressing B1 in the Running state enters the Paused state, and pressing B1 in the Paused state resumes the Running state;
  4. During the Paused state, the valid running time is not accumulated; after resuming, the remaining time continues to accumulate;
  5. When the cumulative valid running time reaches 10 seconds, enter the Completed state; after the Completed state lasts for 3 seconds, return to the Idle state;
  6. Control LD2 according to the current state, making it stay off, blink slowly, stay on, or blink quickly;
  7. Button scanning, state machine processing, LED control, and time management run cooperatively in the main loop, without using blocking delays.
[Board and MCU] NUCLEO-G431RB development board and STM32G431RBT6 MCU.
